# Q1 — ISBAT University Department Homepage

This repository contains the solution for Question 1 of the Web Design Lab Practicals.

## Project
A simple homepage for the ISBAT University Department of Information Technology, built with semantic HTML5 and inline CSS as required by the practical.

## Files
- `index.html` — complete homepage.
- University logo asset — currently referenced from the original lab practical repository so the image remains available while the repositories are being separated.

## Run locally
Open `index.html` in a web browser.

## Deployment
This is a static HTML project and can be deployed directly on Vercel with no build command.
